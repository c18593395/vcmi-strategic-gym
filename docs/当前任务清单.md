**fill_v3_fields 实现细节** (strategic_state.cpp, collect_bc.py 验证 Dungeon Keeper.h3m 10 pairs):
- heroes.total_power = Slots() 遍历 getCreature()->getAIValue() × getCount() 求和
- heroes.is_garrisoned = town->getUpperArmy() dynamic_cast CGHeroInstance 命中 (garrisonHero 是 private!)
- heroes.has_commander = hero->getCommander() != nullptr (commander 是 private, 必须走 getter)
- players.total_power = 该玩家所有英雄战力和; weekly_income = Σ town->dailyIncome()[GOLD] × 7
- relation_to_me: PlayerRelations 枚举 (ENEMIES=0/ALLIES=1/SAME_PLAYER=2) → 映射 0=中立 1=敌对 2=结盟
- towns.recruit_mask = bit=level×2+upgrade, dwelling 建筑 hasBuilt (BuildingID::getDwellingFromLevel)
- towns.build_mask = 只算己方城镇 (owner==0) — canBuildStructure 对敌城打 ERROR 刷屏!
  置位: ALLOWED | CANT_BUILD_TODAY | NO_RESOURCES (排除已建/前置未满足)
- enemy_threat[7] = 排除自己后各玩家 total_power
- battle_pred = active hero total_power / 所在格守卫战力 / win_prob=my×100/(my+target)
- local 通道1 = tile.visitableObjects.front() → getObjInstance → ID (Obj 枚举, int8 保护 <128)
- local 通道2 = guardingCreatures(pos) 守卫战力和, log2 压缩防 int8 溢出

**验证结果** (Dungeon Keeper.h3m, 10 pairs):
- players.total_power 20/80 非零, weekly_income 20, relation 10
- heroes.total_power 35 非零, is_garrisoned 3 (有驻守英雄), has_commander 0 (无指挥官图)
- towns.recruit_mask 20, build_mask 10 (己方城镇 11 个可建 bits)
- enemy_threat 每帧 1 个非零, battle_pred my=2540 win=100
- local ch1 17-21 格/帧, ch2 3-12 格/帧 (log2 压缩后 max=12)
- 24 步采集无崩溃无死锁

**本次新踩坑**:
1. canBuildStructure 对非己方城镇打 ERROR "Town is not owned!" 刷屏拖慢 → build_mask 只算 owner==0
2. CGHeroInstance::commander / CGTownInstance::garrisonHero 都是 private → 必须 getCommander()/getUpperArmy()+dynamic_cast
3. vcmi_loglevel_global="error" 时 logGlobal->warn 被过滤 → 诊断用 fprintf(stderr) 或直接看数据
4. For Sale.h3m 开局建筑已建满/今天已建过 → build_mask=0 是正确行为, 验证换 Dungeon Keeper.h3m
