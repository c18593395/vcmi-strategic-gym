**NK2 估值公式 (Python 移植, 源自 PriorityEvaluator.cpp)**:
```
state_value = resource_value + mine_value + town_value + army_value - threat_penalty

resource_value:
  gold × 0.001 + (wood+ore) × 0.01 + (mercury+sulfur+crystal+gems) × 0.05
  (NK2: getResourcesGoldReward: gold=1:1, 非金=1:100)

mine_value (己方矿):
  mine_type_weight × quantity_weight
  type: 金矿=0.3, 锯木厂/铁矿=0.2, 稀有资源=0.5
  (NK2: 1.0 + getCombinedResourceRequirementStrength, 资源需求越强权重越高)

town_value:
  己方: 2.0 + gold_income × 0.001 + fort_bonus (0/0.2/0.4/0.6)
  敌方未占: 0 (不直接奖, 通过 conquest 差分)
  (NK2: 首都1.5/Castle1.4/Citadel1.2/Fort1.0/无Fort0.8; 己方=min(1,sqrt(armyGrowth/40000))+min(0.3,dailyIncome/10000))

army_value (己方英雄):
  total_power × 0.0001 (所有己方英雄军力总和)
  (NK2: creature.getAIValue() × count)

threat_penalty (敌方威胁):
  enemy_total_power / (our_total_power + 1) × 0.5
  (NK2: enemyHeroDangerRatio = enemyDanger / ourStrength)
```
