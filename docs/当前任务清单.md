> ## ⚠️ 启动训练必带 Windows keepalive（09-18 实证，置顶纪律）
> **每次启动训练后，必须立即拉起 Windows 侧 keepalive，否则 ~60 秒后 WSL idle shutdown 把训练整个带走**：
>
> ```powershell
> Start-Process wsl.exe -ArgumentList '-d','Ubuntu','sleep','infinity' -WindowStyle Hidden
> ```
>
> - WSL 空闲判定只看 **Windows 侧客户端**（终端/keepalive），不看 VM 内训练进程——训练在跑也会被关机（09-18 实证：journalctl 大量 "Stopping homm3-train-v5" 全是 **poweroff 关机流程**，极易误判为外部 stop；`last` 显示 WSL 当天 reboot 9+ 次）。
> - keepalive 是隐藏进程，**360 安全卫士会杀进程+删计划任务（#267：22:31/02:24 两次 idle shutdown 根因）**。**09-19 拍板：不做任何自动启动，每次手工拉起**：
>
> ```powershell
> Start-Process wsl.exe -ArgumentList '-d','Ubuntu','sleep','infinity' -WindowStyle Hidden
> ```
> （或双击 `py/homm3_wsl_keepalive.vbs`；拉起后验证进程数 ≥1：`Get-CimInstance Win32_Process -Filter "Name='wsl.exe'" | ? { $_.CommandLine -like '*sleep*infinity*' }`）
> - 兜底：enabled unit 在 WSL 冷启动时自动恢复训练（02:25 实证零损失），keepalive 只是防冷启动中断。
> - 判活仍按踩坑 #201 三件套（PID etime + 日志 mtime + cgroup/MainPID）；异常重启先查 `wsl bash -c "last | head"` 看 WSL 是否 reboot，再查 journalctl。
> - 指针：踩坑 #114/#201 + 09-18 WSL idle shutdown 循环定性（已固化知识库 09-18 章）。
