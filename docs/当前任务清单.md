### T13.1 序列化逆向 ✅ 完成 (09-11)
- **输出**：`docs/序列化协议规格.md` — 完整二进制序列化格式规格
- **关键发现**:
  - TCP 帧 = [uint32 header][payload]，little-endian，心跳 10s 空包
  - 整数编码 = 变长整数 (LVarInt)，1 byte < 0x3f, 2+ bytes 用 7-bit 分段 + 0x40 负号位
  - 容器: vector/set/map = uint32 长度前缀 + 元素；array = 无长度前缀
  - 字符串: 带全局限去重，首次保存写 length+raw，重复出现写负数 ID
  - 指针: isNull(bool) → pointerID(uint32) → typeID(uint16) → 数据；同一对象只序列化一次
  - optional: present(uint8) + 值；variant: index(int32) + 值；bitset: 按 N≤16/32/64 选 uint16/32/64
  - int3 = 3×si32 变长整数
  - StaticIdentifier (ObjectInstanceID/QueryID/PlayerColor 等) = 直接 int32 变长
  - EntityIdentifier (CreatureID/HeroTypeID/BuildingID/SpellID 等) = encode 为字符串再序列化
  - 类型 ID: 完整注册表 82-215 (RegisterTypes.h)，服务器包 179-212，客户端包 82-177
  - CPackForServer 序列化 = isNull+pid+tid+player+requestID+子类字段
