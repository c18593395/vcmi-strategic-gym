### 剩余问题

#### ⚠️ obs_nz=8 — 状态数据全零
- **根因**: `AAI::yourTurn` 中 `adventure_process_turn` 在 `selectionMade(0, queryID)` 之前调用 `getHeroesInfo()`，此时 query 未回答，英雄列表为空
- **`strategic_state_update` 死代码**: libmlclient.so 内有完整的 `strategic_state_update(CGameState*)` 函数，但无人调用
- **CCallback::gameState() private**: 无法从外部访问 `CCallback` 的 `CGameState` 指针
- **候选方案**:
  1. 改 `AAI.cpp`: 在 async task (selectionMade 后) 调用 `strategic_state_update` — 需有 CGameState 指针访问途径
  2. 改 `CGameInfoCallback` 调用: 用 `getCalendar()` + `getPlayerState()`.getHeroes() 替代 getHeroesInfo() — 需要确认这些 public 方法在 selectionMade 前是否可用
  3. 添加全局 `g_game_state` 指针: 在 `AAI::yourTurn` 的 async task 中设置，`adventure_process_turn` 读取

#### ⚠️ map_size/passability 缺失
当前 fill 不填充地图尺寸和可通行性 — 需补充
