## 🔴 #45: connector/libmlclient/MMAI 三件套统一（当前阻塞点）

### 已知事实

| 发现 | 详情 |
|------|------|
| ep_runner stdout/stderr = DEVNULL | `train_wsl2_ppo_v2.py:59` 子进程所有输出进黑洞 |
| VCMI 重定向 fd 1/2 | CBasicLogConfigurator 可能在启动时接管 stdout/stderr |
| init_vcmi ABI 不匹配 | 旧 connector(3-arg) vs 新 libmlclient(1-arg void*) |
| schema 版本分歧 | 项目源码(BATTLE_SIDE+LINK_SIZES) vs vcmi-native-build(BATTLE_ROUND) |
| CMakeLists.txt 硬编码 | 第 11 行 `set(VCMI_DIR ...)` 覆盖 -D 参数 |
| `__declspec(dllexport)` GCC 不兼容 | MSVC 扩展在 WSL GCC 下报错，用 DLL_EXPORT 宏修复 |
| ep_runner core dump | 因为 schema/ABI 不匹配，VCMI init 阶段段错误 |

### 所需修复

1. **threadconnector.cpp:573** — 调用 `ML::init_vcmi((void*)initargs.get())` 1-arg 版本
2. **CMakeLists.txt** — 改为 `if(NOT VCMI_DIR)` 条件设置
3. **统一 schema** — 确定用 BATTLE_ROUND（旧版）还是 BATTLE_SIDE（新版），三份源码同步
