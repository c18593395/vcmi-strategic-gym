# 地形栅格数据格式设计 (21x21x4)

> 版本: v1 draft | 日期: 2026-08-23 | 关联: Phase I.4 训练地图体系, CNN 地形编码器

---

## 1. 总览

以英雄为中心的 21x21 局部视野, 4 通道, 用于 CNN 学习空间模式。

```
数据量: 21 x 21 x 4 = 1764 int32 = 7,056 字节
视野: 英雄周围 10 格 (上下左右各 10)
覆盖: 36x36 地图 56%, 72x72 地图 29%
存储: 独立输入通道 (不走 reserved, 不影响现有 obs)
```

## 2. 坐标系

```
grid[r][c] 对应地图坐标:
  map_x = hero_x + (c - 10)   c=0 -> x-10, c=10 -> x, c=20 -> x+10
  map_y = hero_y + (r - 10)   r=0 -> y-10, r=10 -> y, r=20 -> y+10

边界: 超出地图范围的格子填 0 (所有通道)
z 层: 用英雄当前 z 层
```

## 3. 通道定义

### C0: 地形类型 (terrain_type)

| 值 | 地形 | 说明 |
|----|------|------|
| 0 | 越界/未知 | 地图外或未定义 |
| 1 | 草地 (grass) | 可走 |
| 2 | 泥地 (dirt) | 可走 |
| 3 | 砂地 (sand) | 可走 |
| 4 | 碎石 (rough) | 可走, 移动消耗高 |
| 5 | 道路 (road) | 可走, 移动消耗低 |
| 6 | 水 (water) | 不可走 (无水行术) |
| 7 | 岩浆 (lava) | 不可走 |
| 8 | 雪地 (snow) | 可走 |
| 9 | 沼泽 (swamp) | 可走, 移动消耗高 |
| 10 | 沙漠 (desert) | 可走 |
| 11 | 岩石面 (rock) | 不可走 |
| 12 | 地下 (subterra) | 可走 |
| 13 | 暗草地 (dark_grass) | 可走 |

编码: 直接用 VCMI ETerrainType 枚举值 (0-13)

### C1: 障碍物 (blocked)

| 值 | 说明 |
|----|------|
| 0 | 可通行 (无阻挡物) |
| 1 | 不可通行 (山/树/岩石/建筑等) |

### C2: 对象类型 (object_type)

| 值 | 对象 | 说明 |
|----|------|------|
| 0 | 空 | 无可交互对象 |
| 1 | 矿 (mine) | 金矿/锯木厂/铁矿/稀有矿 |
| 2 | 城镇 (town) | 己方/敌方城镇 |
| 3 | 资源 (resource) | 地面资源 |
| 4 | 宝箱 (treasure_chest) | 经验/金币 |
| 5 | 怪物 (monster) | 野怪守卫 |
| 6 | 英雄 (hero) | 己方/敌方英雄 |
| 7 | 宝物 (artifact) | 装备 |
| 8 | 建筑 (dwelling) | 生物招募点 |
| 9 | 传送门 (teleport) | 传送门/入口 |
| 10 | 其他 | 其他可交互对象 |

### C3: 可见性 (visibility)

| 值 | 说明 |
|----|------|
| 0 | 未探索 (fog of war) |
| 1 | 已探索 (可见) |

训练期全可见, 部署期用 fogOfWarMap.

## 4. C++ 侧: fill_terrain_grid()

```cpp
// strategic_state.h 新增:
#define GRID_SIZE 21
#define GRID_CHANNELS 4
#define GRID_TOTAL (GRID_SIZE * GRID_SIZE * GRID_CHANNELS)  // 1764

struct StrategicState {
    // ... 现有字段 ...
    int32_t reserved[RESERVED_SIZE];      // 134 (现有)
    int32_t terrain_grid[GRID_TOTAL];     // 1764 (新增)
};
```

```cpp
// strategic_state.cpp 新增:
static void fill_terrain_grid(StrategicState* state, CGameInfoCallback* gicb) {
    auto& gs = gicb->gameState();
    auto& map = gs.getMap();

    int ah = state->active_hero;
    if (ah < 0 || ah >= MAX_HEROES || state->heroes[ah].id < 0) return;

    const CGHeroInstance* hero = dynamic_cast<const CGHeroInstance*>(
        gs.getObjInstance(ObjectInstanceID(state->heroes[ah].id)));
    if (!hero) return;

    int3 hpos = hero->visitablePos();
    int hx = hpos.x, hy = hpos.y, hz = hpos.z;
    int W = state->map_width, H = state->map_height;

    memset(state->terrain_grid, 0, sizeof(state->terrain_grid));

    for (int r = 0; r < GRID_SIZE; r++) {
        for (int c = 0; c < GRID_SIZE; c++) {
            int mx = hx + (c - GRID_SIZE/2);
            int my = hy + (r - GRID_SIZE/2);

            if (mx < 0 || mx >= W || my < 0 || my >= H) continue;

            int idx = (r * GRID_SIZE + c) * GRID_CHANNELS;
            auto& tile = map.getTile(int3(mx, my, hz));

            // C0: terrain type
            state->terrain_grid[idx + 0] = (int32_t)tile.terrainType;

            // C1: blocked
            state->terrain_grid[idx + 1] = tile.blocked() ? 1 : 0;

            // C2: object type
            int obj_type = 0;
            if (!tile.visitableObjects.empty()) {
                auto obj = gs.getObjInstance(tile.visitableObjects.front());
                if (obj) {
                    if (dynamic_cast<CGMine*>(obj)) obj_type = 1;
                    else if (dynamic_cast<CGTownInstance*>(obj)) obj_type = 2;
                    else if (dynamic_cast<CGResource*>(obj)) obj_type = 3;
                    else if (dynamic_cast<CGCreature*>(obj)) obj_type = 5;
                    else if (dynamic_cast<CGHeroInstance*>(obj)) obj_type = 6;
                    else if (dynamic_cast<CGArtifact*>(obj)) obj_type = 7;
                    else if (dynamic_cast<CGDwelling*>(obj)) obj_type = 8;
                    else if (dynamic_cast<CGTeleport*>(obj)) obj_type = 9;
                    else obj_type = 10;
                }
            }
            state->terrain_grid[idx + 2] = obj_type;

            // C3: visibility (训练期全可见)
            state->terrain_grid[idx + 3] = 1;
        }
    }
}
```

## 6. CNN 编码器架构

```python
class TerrainCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(4, 32, 3, padding=1),   # 21x21x32
            nn.ReLU(),
            nn.MaxPool2d(2),                    # 10x10x32
            nn.Conv2d(32, 64, 3, padding=1),   # 10x10x64
            nn.ReLU(),
            nn.MaxPool2d(2),                    # 5x5x64
            nn.Conv2d(64, 128, 3, padding=1),  # 5x5x128
            nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),            # 1x1x128
        )
        self.fc = nn.Linear(128, 128)

    def forward(self, x):
        # x: (batch, 4, 21, 21)
        x = self.conv(x)
        x = x.view(x.size(0), -1)
        return self.fc(x)           # (batch, 128)
```

## 7. Net() 集成 (方案2: 独立通道)

```python
class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.main_branch = nn.Sequential(
            nn.Linear(3464, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU(),
        )
        self.terrain_cnn = TerrainCNN()
        self.actor = nn.Linear(128 + 128, 25)
        self.critic = nn.Linear(128 + 128, 1)

    def forward(self, obs_main, obs_terrain=None):
        feat_main = self.main_branch(obs_main)
        if obs_terrain is not None:
            feat_terrain = self.terrain_cnn(obs_terrain)
            feat = torch.cat([feat_main, feat_terrain], dim=1)
        else:
            feat = torch.cat([feat_main, torch.zeros_like(feat_main)], dim=1)
        return self.actor(feat), self.critic(feat)
```
