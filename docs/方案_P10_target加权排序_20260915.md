## 2. 设计目标
- 用**单一数值打分排序器**替代五层 if/else：所有候选同池打分，分数高者承接 MOVE_TO。
- **OBS 3464 / 动作空间零变更**（铁律）：排序只发生在 Python 消费侧；C++ target_list 视为"候选源之一"而非全部。
- **零 .so 重编**：候选全量化走 Python（vmap 静态索引已有 `get_guards/get_objectives` 先例；动态信息读 obs 英雄/城镇段）。
- 保留全部已验证硬护栏（黑名单/stall/BFS 可达/限次/粘滞）为**硬约束层**，打分只在通过约束的可行候选间排序。
- 参数全部 argparse 化 + 开关可回退旧链，支持 eval_promo 对照。

## 3. 统一打分器设计

### 3.1 候选池（Python 侧每步重建，同层 z=active_hero.z）
| 源 | 类型 | 信息 |
|----|------|------|
| C++ target_list obs[3251:3315] | 矿/资源/篝火/宝箱/宝物 | dist、log2guard（D1 的 top-8 截断只影响此源） |
| vmap 静态索引（新增缓存） | **全部**矿（含已占）、城镇、守卫出生点 | 一次解析缓存；补齐 D1/D2 候选缺失 |
| obs 英雄段 obs[128:336] | **蓝/敌方英雄动态位**（owner≠0 且 alive） | pos、total_power（D4/D6，动态真实） |
| obs 城镇段 obs[336:480] | 全部城镇（owner 区分蓝城/己城） | recruit_mask、garrison |

### 3.2 打分公式（候选 c，当前阶段 s）
```
score(c) = W_type·V(c,s)                          # 类型基础价值（阶段调制）
         + W_win ·Δcapture(c)                     # 对 1v3 终极目标的贡献（蓝英雄/蓝城）
         + W_pow ·F(power_self, power_c)          # 可打性：logistic(战力差)，打不过→强负
         - W_dist·g(plen_bfs)                     # 真实路径长度（BFS，非曼哈顿）
         + W_stick·𝟙(c==当前目标)·f(stall_count)  # 粘滞 bonus，随 stall 衰减
         - P_phase(c,s)                           # 阶段错配惩罚
其中 g(d)=d（线性，参数可换 1−exp(−d/τ)）；不可达候选不进池（硬约束）。
```
要点：
- **价值 V**：蓝英雄=最高（1v3 每个 +100 capture 语义）＞蓝城＞未占矿＞宝箱/宝物/篝火＞资源堆；已占矿 V=0（解决 D5 跳变：矿在占前持续降权而非布尔消失）。
- **可打性**：`F = 2σ((log power_self − log power_c − margin)/T) − 1`，守卫/蓝英雄共用；power_self 取 obs active hero total_power（+ 可选 garrison 合兵预估）。打不过的目标不是剔除而是强负分——兵力成长后自然回升（连续替代黑名单；黑名单保留给引擎拒入/振荡的状态机场景）。
- **Δcapture**：1v3 下蓝英雄按其存活稀缺性加权（剩得越少单杀价值越高）；蓝城在 T06 阶段 V 直接拉满（把 `_t06_direct` 特例吸收进阶段项，删 D1 补丁）。
- **距离一律 BFS plen**（bfs_full_dir 已在用于城镇/己城），消灭曼哈顿误判（D1/D2 同源）；plen 预算惩罚：T06 剩余步数容不下往返的候选额外惩罚（把 76-79 行取兵限次的理由数值化）。
- **阶段 s**：economy 窗（economy_force）/ capture 阶段（T06 直达 or mine_taken）由现有信号派生，只调制 V 与 P_phase，不改奖励。

### 3.3 硬约束层（打分前过滤，全部沿用现机制）
- BFS `_dir is None` → 不入池（不可达不烧学费）。
- `guard_blacklist`（位置重合 + fail-count≥3）、`town_blocked`、`dyn_blocked`。
- 回城取兵 T06 限次 2 保留为硬上限（或转为 score 惩罚，二选一，实现期 A/B 定）。
- `move_stall` 6 步放弃保留；放弃目标进本局 cooldown（比永久 blocked 更细）。
- 守卫格 passable=0 的特殊移动标志保留。

- D4 修复后，72_02 失败局剧本（蓝城 (69,2) stall → 朝东撞墙 90 步）中，蓝英雄入池且为动态高分目标，引导在蓝城不可达/被堵时自动承接最近蓝英雄而非空转——**可能不挪蓝镇就解掉部分 200 截断**；但这是干预假设，须探针局验证，不能替代改图判据修订。
