> 判据核对：规则 18 条（≥15）✓；每条含 触发/动作/优先级/落点类 ✓；5 原型 seed 映射 ✓；每条标注 NK2 骨架类可复用度 ✓。

## 一、架构定谳（从源码坐实的三件事）

### 1.1 NK2 是 OBJECT 库，进 libvcmiMain
- `ai/Nullkiller2/CMakeLists.txt` L155：`add_library(Nullkiller2 OBJECT ...)` + L159 `target_link_libraries(Nullkiller2 PUBLIC vcmiMain TBB::tbb)` → NK2 源码编译进 libvcmiMain，符号全局可见。
- **推论**：新 AI 模块可以 `NK2AI::AIGateway` 为基类**继承复用**（NK2 全部骨架在 libvcmiMain 里可链接），而 T14BlueMod 自身编**独立 .so**，不碰任何引擎文件。

### 1.2 AIFactory 的注册方式（可插拔机制，含一个待验点）
- `lib/callback/AIFactory.cpp`：`"Nullkiller2"` 名 → `make_shared<NK2AI::AIGateway>()`（编译期，门控 `ENABLE_NULLKILLER2_AI`）；MMAI 注释明说 "loaded at runtime via the AI plugin system"。
- **T14BlueMod 路线 = MMAI 范式**（`ai/MMAI/main.cpp` 入口 822B 全量可抄）：
  ```
  extern "C" DLL_EXPORT int GetGlobalAiVersion();      // 返回 AI_INTERFACE_VER
  extern "C" DLL_EXPORT void GetAiName(char*);         // "T14Blue"
  extern "C" DLL_EXPORT void GetNewAI(shared_ptr<CGlobalAI>&);      // make_shared<T14BlueGateway>()
  extern "C" DLL_EXPORT void GetNewBattleAI(...);      // 委托 V13 BAI（onnx 战斗 AI，R6）
  ```
  产物 `AI/T14Blue.so`（CMake `vcmi_set_output_dir` 同 MMAI L161 模式）。
- **⚠ 待验点 T14.3 首验**：引擎对 lobby AI 名 `T14Blue` 的 dlopen 路径（`isAvailableAdventureAI` 在引擎本体写死 false）是否放行——引擎侧若先查 `isAvailable` 再 dlopen，则 lobby 传 "T14Blue" 会被拒。备选 = 名字直接传 `dllName` 走 dlopen 直通（MMAI 同款名字即直接可查）。**T14.3 冒烟第一件事 = 单局验证加载通路**，不通再定备选（不预设改引擎）。

### 1.3 NK2 骨架复用面（T14BlueMod 只写薄层）
| 层 | NK2 类（libvcmiMain 内可链接） | T14 用法 |
|----|----|----|
| 回合主循环 | `Engine/Nullkiller`（makeTurn：更新→分解→优先级→执行，L128-172） | **基类继承**，覆盖极小 |
| 事件网关 | `AIGateway`（yourTurn/query 应答，58KB） | 派生 `T14BlueGateway : NK2AI::AIGateway` |
| 20+ 子目标 | `Goals/*`（RecruitHero/BuyArmy/BuildThis/ExploreNeighbourTile/CompleteQuest/ExecuteHeroChain…） | 原样复用，改权重 |
| 13 行为 | `Behaviors/*`（DefenceBehavior 20KB / ExplorationBehavior / GatherArmyBehavior / StartupBehavior…） | 原样复用，改优先级 |
| 5 分析器 | `Analyzers/*`（BuildAnalyzer / HeroManager / ArmyManager / DangerHitMapAnalyzer / ObjectClusterizer） | 原样复用 |

| 调参 | `Engine/Settings`（`nk2ai-settings.json` 按 difficulty 加载） | **新增 T14 专属 JSON 原型档 + handicap 段** |

**工程量结论**：T14.3 实际 = ① `ai/T14BlueMod/` 新目录（main.cpp 入口 + T14BlueGateway.h/.cpp 薄派生层 + 原型/handicap 逻辑 ~800-1500 行）② CMake 一个 `add_subdirectory`（门控 `ENABLE_T14_BLUE_AI`，默认关，零影响存量构建）③ `config/ai/t14blue/` JSON。NK2 全部逻辑不复制不修改。

## 二、NK2 骨架地图（规则落点索引）

```
AIGateway (yourTurn 入口, L69 类)
├─ Nullkiller::makeTurn            ← 主循环：updateState → decompose → 优先级 pass → executeTask
├─ Behaviors (13)  ← 行为级目标生成
│   Startup / Exploration / Defence(20KB) / GatherArmy / RecruitHero /
│   BuyArmy / Building / CaptureObjects / Cluster / StayAtTown / Escape
├─ Goals (20+)     ← 原子子目标（每个 = 触发条件 + 分解产物）
├─ Analyzers (5)   ← 态势计算（Build/Hero/Army/危险热区/对象聚类）
├─ PriorityEvaluator (63KB) ← 全局打分，规则权重改这里的输入
└─ Settings        ← JSON 调参（config/ai/nk2ai/nk2ai-settings.json）
```

## 四、5 原型 × seed 参数化（同 seed 必同行为）

| 原型 | 主攻节奏 | 关键参数（覆盖 nk2ai-settings 段） | 特征动作 |
|------|---------|-----------------------------------|---------|
| P0 龟速经济 | 经济优先 | R14 权重 3×、R11 关闭、maxGoldPressure=0.6、R12 保留 4 队 | 满矿满建，20 天后才总攻 |
| P1 速攻 | 前期rush | R11 顶格、R16 提前至 10 天、scout 关闭、R18 阈值放宽 0.5 | 7 天出门 15 天攻城 |
| P2 游击 | 骚扰 | R10 关闭（分散 4 英雄）、R18 严 0.2、R15 副力权重 2× | 多小股袭扰不打主力战 |
| P3 飞兵骚扰 | 高机动 | R5/R6 门控放宽（15/20 级）、R14 目标=敌方城镇（不是资源） | 飞行/传送直取城 |
| P4 均衡 | 标准 | NK2 默认权重 + handicap 全开 | 类 NK2 但带 handicap |

**seed 映射公式**（T14BlueGateway 构造时一次性决定，写入 `AIMemory` 每局打印可审计）：
```
hash = FNV1a(gameSeed ^ mapHash ^ salt_T14)
archetype = P[hash % 5]
aggression = (hash >> 3) % 4          // 0-3 激进度（调 R16/R18 阈值曲线）
handicap_on = (hash >> 5) % 2         // handicap 全开/半开（R2/R3/R4/R7 开一半时数值减半）
```
- **确定性**：全部随机量走引擎 RNG（`cb->getRNG()` 族，NK2 `ResourceTrader`/`FuzzyHelper` 已有先例），禁 `std::random_device`/系统时钟 → 同 gameSeed+地图 必同原型同行为。T14.4 可复现判据 = 同 seed 两局 action 序列 hash 相等（T14.3 加 `[T14-ACT]` 逐回合打点支撑）。

**技术事实（架构定谳）**
1. VCMI 1.4+ 官方 handicap API = `config/difficulty.json`（globalBonuses/battleBonuses，按 difficulty 分档；`startres.json` 已废弃，vcmi.eu/modders/Difficulty 坐实）。**→ handicap 整层纯 JSON，0 行 C++**。
2. 官方 PR #7669（2026-08，MichalZr6）"[WIP] Improve NK2AI adventure map decisions"——NK2 决策持续变强，T14.4 基线对照须记 NK2 版本号。
3. overall-ai-bonus 明确注明 Resourceful AI 1.2（startres 路线）在 1.4+ 失效——验证"只用 difficulty.json"的必要性；兼容性须按我方 fork（1.8 系）逐个验。
