## Phase C: 战略 RL 训练 ⬜

> 目标：用自对弈 PPO 训练战略模型，ELO 持续上升。

### C1: 基础训练

| # | 任务 | 说明 |
|---|------|------|
| C1 | 适配 mppo.py 到战略环境 | 注册 strategic_env，配 YAML config |
| C2 | 空图训练 | 无对手，先学移动 + 捡资源 + 结束回合 |
| C3 | 弱 AI 对手训练 | vs StupidAI，学占矿 + 打野怪 |
| C4 | 自对弈训练 | 对手池 + ELO 追踪，学对抗策略 |

### C2: 自对弈架构

```
Round 1:   v1(红) vs v1(蓝) → 探索规则
Round 50:  v50(红) vs v48(蓝) → 持续进步
Round 500: v500(红) vs v495(蓝) → 高手对决
```

对手池保留最近 20 个版本，70% 最新 + 20% 早期 + 10% 随机。

### C3: 训练规模

| 阶段 | 轮次 | 时间 | 说明 |
|------|------|------|------|
| 基础 | ~200 轮 | 1天 | 学会基本操作 |
| 对抗 | ~500 轮 | 2-3天 | 学会占矿/攻城/防守 |
| 强化 | ~1000 轮 | 5-7天 | 高阶策略，能赢 BattleAI |
| 精炼 | ~2000 轮 | 2周 | 能赢大多数人类玩家 |

## Phase D: 战斗集成 ⬜

> 目标：战略遇敌时调用战斗模型，战果回传。

| # | 任务 | 说明 |
|---|------|------|
| D1 | 遇敌检测 | strategic_state 中 hero.in_battle 标志 |
| D2 | 切换战斗模式 | 遇敌时暂停战略 Agent，启动战斗 Agent |
| D3 | 战果回传 | 战斗胜负 → 战略层知道要不要撤退 |
| D4 | 自对弈战斗 | 红蓝双方都用训练好的模型裁决 |
| D5 | 梯度阻断 | 战斗层不反向传播到战略层（分层 RL） |

## Phase E: 真实游戏部署 ⬜

> 目标：训练好的模型在真实 HoMM3 HD Mod 中运行。

| # | 任务 | 说明 |
|---|------|------|
| E1 | 内存读取适配 | heroes3_bridge.py 偏移验证 (HD Mod 5.5) |
| E2 | 状态映射 | VCMI 观测 → 真实游戏观测 (可能需适配层) |
| E3 | 动作执行 | PostMessage 按键映射表，执行战略动作 |
| E4 | 模型加载 | ONNX Runtime 在本地加载训练好的 .onnx |
| E5 | 推理循环 | 读内存 → 模型推理 → 执行动作 → 循环 |
| E6 | 手动接管 | 你在任意时刻接管控制权 |
| E7 | 端到端测试 | 你开游戏选英雄 → AI 接手全盘 |
