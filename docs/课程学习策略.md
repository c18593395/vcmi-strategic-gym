# 课程学习策略

## 概述

课程学习 (Curriculum Learning) 是一种训练策略，从简单任务开始，逐步增加难度，帮助模型更好地学习。

## Level 0-5 课程计划

## 课程学习配置

### 地图池配置

```yaml
curriculum:
  level_0:
    maps: ["T01_adventure_20X20_01.vmap", "T01_adventure_20X20_02.vmap", ...]
    episodes: 1000
    promotion_threshold:
      positive_reward_rate: 0.5
      average_reward: 0
      window: 100
  
  level_1:
    maps: ["T02_adventure_20X20_01.vmap", ...]
    episodes: 1000
    promotion_threshold:
      positive_reward_rate: 0.6
      average_reward: 5
      window: 100
  
  # ... 更多 Level
```

### 自动晋级逻辑

```python
def check_promotion(metrics, level):
    """检查是否满足晋级条件"""
    threshold = CURRICULUM[level]["promotion_threshold"]
    
    if (metrics["positive_reward_rate"] > threshold["positive_reward_rate"] and
        metrics["average_reward"] > threshold["average_reward"]):
        return True
    return False
```

### 动态难度调整

- 如果模型在当前 Level 表现优秀，提前晋级
- 如果模型在当前 Level 表现不佳，延长训练
- 最大延长: 2000 episodes per Level

## 训练计划

### 总时长估算

- Level 0: 1000 episodes ≈ 5 天
- Level 1: 1000 episodes ≈ 5 天
- Level 2: 1000 episodes ≈ 5 天
- Level 3: 1000 episodes ≈ 5 天
- Level 4: 1000 episodes ≈ 5 天
- Level 5: 1000 episodes ≈ 5 天

**总计**: 6000 episodes ≈ 30 天

### 监控指标

1. **正奖励率**: 正奖励 episodes 占比
2. **平均奖励**: 所有 episodes 平均奖励
3. **KL 散度**: 策略变化幅度
4. **动作分布**: 各动作使用频率
5. **战斗胜率**: 战斗 episodes 胜率 (Level 2+)
6. **资源收集率**: 成功收集资源 episodes 占比

### 检查点保存

- 每 100 episodes 保存检查点
- 晋级时保存检查点
- 训练中断时保存检查点

## 实现计划

### Phase 1: 基础设施 (1天)

1. 创建课程学习配置文件 `curriculum_config.yaml`
2. 创建课程学习管理器 `curriculum_manager.py`
3. 修改训练脚本支持课程学习

### Phase 2: Level 0 训练 (5天)

1. 使用 T01 地图训练 1000 episodes
2. 监控评估指标
3. 满足晋级条件后进入 Level 1

### Phase 3: Level 1-5 训练 (25天)

1. 逐步训练 Level 1-5
2. 监控每个 Level 的评估指标
3. 根据表现调整训练时长

### Phase 4: 评估和优化 (持续)

1. 评估最终模型性能
2. 分析学习曲线
3. 优化课程学习策略
