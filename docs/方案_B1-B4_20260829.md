## B3: 开局熵 bonus 方案

### 依据 (Task4 反直觉发现)
- 67% 局以固定 3/7 序列开局, 但徘徊局 r 中位 9.6 **高于**其他开局 1.7 → 固定开局是该图 (44% blocked) 的近优策略, 不是病
- 病在"从不尝试别的开局": 开局 6 步动作熵 ≈0, 一旦环境变化 (换图/对手池) 无适应能力
- 因此: 不做开局惩罚 (压制必要搜索), 做探索维持

### 方案: episode 前段的动作熵 bonus (训练侧, 非环境奖励)
```python
# train_wsl2_ppo_v2.py PPO loss 段 (L384 现状: loss = surr + 0.5*vloss - 0.05*ent)
ENT_COEF_BASE = 0.05
ent_t = ent_coef * (1.0 + 1.0 * math.exp(-global_step / 2_000_000))  # 前期×2, 200万步衰减到×1
loss = surr + 0.5*vloss - ent_t*pi.entropy().mean()
```
- 与现有 ent_coef=-0.05 系数兼容, 只是前期抬升后衰减; 不动 ep_runner (无每步奖励污染)
- 全局动作熵兜底: 监控 act 频率分布熵, 若 3/7+10 合计 >85% 持续 200 局 → 告警 (人工介入信号)

### 备选 (不推荐): 开局随机强制方向
- ep_runner 前 N 步从 passable 里均匀采样 — 实现最简单, 但污染 PPO 采样分布 (08-19 move_to_force 教训的对称风险), 只当 entropy 方案无效的兜底

### 实装前置
- D3 触发: 自然重启窗口 (改 train 脚本须重启); 与 D1/D2 错开, 一次一轴
- 验收: 开局 6 步动作熵 (前 200 局滑动) 较基线 +50% 以上, avg_r 无回退 >20%
