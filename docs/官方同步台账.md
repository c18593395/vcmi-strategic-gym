## 5. 刷新流程（每次窗口期前跑一遍）

1. **Windows 侧**（WebFetch，WSL 无外网）：
   - `https://github.com/vcmi/vcmi/pulls?q=is:pr is:closed merged:>{上次基点日期}` 逐页过
   - 关注作者 starius / smanolloff / IvanSavenko + 关键词 battle/query/garrison/serializer/pathfinder/RMG
2. **WSL 侧**：
   - `wsl -e bash py/sync_surface_scan.sh` — 刷新分叉面快照（本台账第 1 节）
   - `wsl -e bash py/verify_upstream_nk2_local.sh` — 反向同步检查（关键词可按当期 PR 增删）
3. 逐条定级入表（第 3 节），变更记录写入第 6 节
4. 窗口执行时：每条 PR 先跑 merge7632_survey.sh 模式的 per-PR 冲突面调研，再决定 patch / 放弃
